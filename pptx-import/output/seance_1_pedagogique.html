Slide 5

Les composants internes — Rôle de chacun

Carte mère (Motherboard)

La plateforme centrale. Tous les composants s'y connectent. Format ATX / mATX / ITX. Détermine la compatibilité de tout le reste.

CPU (Processeur)

Cerveau du PC. Exécute les instructions. Intel (Core i3/i5/i7/i9) ou AMD (Ryzen). Fréquence en GHz + nombre de cœurs = performance.

RAM (Mémoire vive)

Mémoire de travail temporaire. DDR4 ou DDR5. En GB. Insuffisante → PC lent. S'efface à chaque extinction.

SSD / HDD (Stockage)

Stockage permanent. SSD = rapide (flash). HDD = lent (mécanique). Windows + programmes + vos fichiers vivent ici.

Alimentation (PSU)

Convertit le 220V AC en tensions DC utilisables (12V, 5V, 3.3V). Trop faible = instabilité. Toujours choisir une marque fiable.

Carte graphique (GPU)

Traite l'affichage vidéo. Intégrée (CPU) ou dédiée (NVIDIA/AMD). Essentielle pour jeux et montage vidéo.

Pour diagnostiquer un PC : identifier d'abord quel composant est en cause

Slide 7

La RAM — Mémoire de travail temporaire

Définition :

La RAM (Random Access Memory) est la mémoire où le CPU place temporairement les données qu'il utilise activement. C'est comme un bureau de travail : rapide, accessible immédiatement — mais qui se vide entièrement à chaque extinction.

Pourquoi c'est important :

RAM insuffisante

Le PC utilise le disque comme RAM (swap) → 50× plus lent

RAM saturée

Symptôme : PC lent, application qui freeze, erreur mémoire

Plus de RAM

Permet plus d'applications ouvertes simultanément

Type DDR

DDR4 (PC anciens) ou DDR5 (PC récents) — incompatibles entre eux

CHIFFRES CLÉS — RAM

4 GB

8 GB

Standard bureautique — acceptable

16 GB

Recommandé 2024 — confortable

32 GB+

Montage vidéo / développement / jeu AAA

DDR4 3200

Standard des PC 2017-2022

DDR5 4800+

Standard des PC 2022+ (Intel 12e gen+)

Diagnostic rapide : Task Manager → onglet Performances → Mémoire → voir % utilisation

Slide 10

Le CPU — Comment lire les performances d'un processeur

Savoir lire les specs CPU vous permet de donner une recommandation terrain rapide.

Fréquence

Fréquence (GHz)

Vitesse de chaque cœur. Plus c'est élevé, plus chaque tâche individuelle est rapide. Limite : la fréquence max est bridée thermiquement.

Ex : Intel i5-12400 : 2.5 GHz base / 4.4 GHz boost

Nombre de coeurs

Nombre de cœurs

Capacité à faire plusieurs choses en parallèle (multitâche). 6 cœurs = peut traiter 6 tâches simultanées sans ralentissement.

Ex : i5-12400 : 6 cœurs / 12 threads (HyperThreading)

Cache

Cache (L1/L2/L3)

Mémoire ultra-rapide intégrée au CPU. Le CPU cherche ici avant d'aller en RAM. Grand cache = moins d'attente = performances meilleures.

Ex : i5-12400 : 18 MB de cache L3

TDP

TDP (Watts)

Consommation énergétique et chaleur produite. Important pour le choix du ventirad. PC portable : CPU basse conso (15-28W). Desktop : 65W à 125W.

Ex : i5-12400 : 65W TDP → ventirad stock suffisant

CPU-Z (gratuit cpuid.com) → onglet CPU → voir fréquence, cœurs, cache en temps réel

Slide 11

La carte mère — Tout s'y connecte

Socket CPU

Accueille le processeur. Intel LGA 1700 ≠ AMD AM5 — incompatibles.

💡 Toujours vérifier la compatibilité socket avant d'acheter un CPU.

Slots RAM (DIMM)

2 à 4 emplacements pour les barrettes DDR4/DDR5. Couleurs : slots A et B.

💡 Insérer en A2 si 1 barrette · A2+B2 si 2 barrettes (Dual Channel).

Slots PCIe

Connecteurs pour GPU, cartes réseau, SSD M.2 en x16, x4, x1.

💡 PCIe 4.0 > PCIe 3.0 — vérifier la génération pour NVMe rapide.

Ports SATA

Connectent les SSD 2.5" et HDD. 4 à 6 ports par carte mère.

💡 Chaque port = 1 disque maximum. Câble SATA + alimentation.

Connecteurs panneau

Bouton power, reset, LEDs, USB frontal — câbles du boîtier.

💡 Référence : manuel de la carte mère pour le pinout exact.

BIOS/UEFI

Firmware qui démarre avant Windows. Configure boot, overclock, XMP.

💡 Accès : F2, Suppr ou F10 selon la marque au démarrage.

CPU-Z onglet Mainboard : fabricant, modèle, version du BIOS — infos essentielles pour le support

VirtualBox — Créer votre environnement de travail

Une VM (machine virtuelle) = un PC entier simulé dans votre PC. Tout casser dans la VM = aucun risque sur votre vrai PC.

01Télécharger VirtualBox
virtualbox.org → Download → Choisir Windows Hosts
⚡ Gratuit, open source, ~105 MB
02Télécharger l'ISO Windows 11
microsoft.com/software-download/windows11 → Télécharger l'image disque (ISO)
⚡ Gratuit et légal — ~5.8 GB
03Créer une nouvelle VM
VirtualBox → Nouvelle → Nom : 'Pratique S1' Type : Microsoft Windows → Version : Windows 11 (64-bit)
04Configurer la mémoire
Mémoire vive : 4096 MB minimum (50 % de votre RAM) Processeurs : 2 minimum
⚡ Ne jamais dépasser 60 % de votre RAM réelle
05Créer le disque virtuel
Créer un disque VDI → Dynamiquement alloué → 50 GB
⚡ VDI = disque virtuel dans un fichier sur votre vrai disque
06Démarrer et installer
Démarrer la VM → Insérer l'ISO → Suivre l'installation
⚡ Durée : 20-40 min selon votre PC
Snapshot VirtualBox : Machine → Prendre un instantané → sauvegarder l'état → toujours revenir en arrière

Slide 17

Les 5 questions — À poser AVANT de toucher à quoi que ce soit

Ces questions s'appliquent à chaque panne, chaque appel client, de la S1 à la fin de votre carrière.

1

Qu'est-ce qui ne fonctionne pas ?

Écouter les mots EXACTS du client. Ne pas interpréter. Reformuler pour confirmer : 'Si je comprends bien, le problème c'est...'

2

Depuis quand exactement ?

Récent (1-2 jours) = changement récent probable. Ancien (semaines/mois) = usure progressive ou évolution lente.

3

Vous avez changé quelque chose ?

Mise à jour Windows, nouvelle installation, déplacement du PC, chute. Les clients oublient souvent — relancer avec : 'Même une petite chose ?'

4

Ce PC seulement ou d'autres aussi ?

Tous les PC du bureau = réseau ou serveur → escalade possible. Un seul PC = problème localisé sur ce PC spécifiquement.

5

Vous pouvez me montrer le problème en direct ?

Voir par soi-même est irremplaçable. Ne jamais diagnostiquer uniquement sur une description. Partage d'écran ou déplacement si nécessaire.

Le redémarrage résout 50 % des cas — mais le poser avant les 5 questions = perdre de l'information
