Slide 4

SMB — Protocole de partage Windows

SMB = Server Message Block. Protocole natif Windows pour partager fichiers, imprimantes et ressources réseau.

Partager un dossier — Procédure complète :

1

Clic droit sur le dossier à partager

Propriétés → onglet Partage → Partager

2

Ajouter les utilisateurs

Taper le nom d'utilisateur → Ajouter · 'Tout le monde' pour accès libre sur réseau de confiance

3

Définir les droits

Lecture = peut voir · Lecture/Écriture = peut modifier · Propriétaire = contrôle total

4

Valider le partage

Cliquer Partager → noter le chemin UNC : \\NomPC\NomDossier

5

Activer la découverte réseau

Paramètres → Réseau → Options de partage avancé → Découverte réseau : Activé

6

Tester depuis l'autre PC

Explorateur → \\NomPC → vérifier l'accès → saisir credentials si demandé

!

Découverte réseau désactivée = partage existe mais invisible — cause n°1 des 'impossible de trouver le PC'.

Slide 5

NTFS vs Permissions de partage — La règle du plus restrictif

Un utilisateur a 2 couches de permissions en accès réseau : partage ET NTFS. C'est la plus restrictive qui s'applique.

Configurées dans Propriétés → Partage → Partager

Contrôlent qui peut accéder via le réseau. 3 niveaux : Lecture · Lecture/Écriture · Propriétaire

Exemple : Jean = Lecture/Écriture dans le partage

Configurées dans Propriétés → Sécurité

Contrôlent les droits sur les fichiers et dossiers réels. Plus granulaires : Lecture · Écriture · Exécuter · Contrôle total

Exemple : Jean = Lecture seulement dans la sécurité NTFS

La plus restrictive des 2 s'applique

Si partage = Lecture/Écriture mais NTFS = Lecture → Résultat = Lecture seulement (NTFS gagne)

Exemple : Jean voit les fichiers mais ne peut pas modifier (NTFS gagne)

Bonne pratique : mettre le partage sur Tout le monde = Lecture/Écriture et gérer finement avec les permissions NTFS.

Slide 6

Lecteur réseau monté — Accéder au partage comme un disque

Mapper un partage réseau comme un disque Z: = accès direct depuis l'Explorateur, comme un disque local.

Via l'Explorateur Windows

1

Ce PC (Ordinateur) → Connecter un lecteur réseau (dans le menu Ordinateur)

2

Choisir la lettre : Z: (ou autre disponible)

3

Dossier : \\NomPC\NomDossier (chemin UNC du partage)

4

Cocher 'Se reconnecter à l'ouverture de session' = permanent

5

Cocher 'Se connecter avec d'autres informations d'identification' si compte différent

Via CMD ou PowerShell

1

net use Z: \\NomPC\NomDossier

2

Avec credentials : net use Z: \\NomPC\Dossier /user:NomUser MotDePasse

3

Persistant : ajouter /persistent:yes à la fin

4

Lister les lecteurs montés : net use

5

Supprimer : net use Z: /delete

Dépannage lecteur réseau

1

Lecteur rouge X au démarrage : PC cible éteint ou nom changé

2

Réinitialiser : net use * /delete → puis remapper

3

Si erreur 'Accès refusé' : vérifier permissions NTFS et partage

4

Si erreur 'Introuvable' : vérifier découverte réseau · ping NomPC

5

Alternative URL : \\IP_du_PC\NomDossier (si le nom ne résout pas)

Slide 7

OneDrive — Configuration de la synchronisation

OneDrive = stockage cloud Microsoft 365. Intégré à Windows 11. 5 GB gratuits. 1 TB avec Microsoft 365.

Configurer la sauvegarde automatique

Clic droit icône OneDrive → Paramètres → Sauvegarde → Gérer la sauvegarde Cocher : Bureau · Documents · Images Ces 3 dossiers sont synchronisés en permanence sur le cloud.

💡 Si PC volé ou HS → retrouver tous les fichiers sur onedrive.com depuis n'importe où

Fichiers à la demande

Paramètres OneDrive → Paramètres → Fichiers à la demande Fichiers 'online only' = visible dans l'Explorateur mais non téléchargé (0 espace) Téléchargé à l'ouverture — Disponible hors ligne = copie locale conservée.

💡 Économiser l'espace disque sur laptop : 100 GB de fichiers = 0 MB utilisé si non ouverts

Synchronisation sélective

Clic droit icône OneDrive → Paramètres → Compte → Choisir des dossiers Cocher uniquement les dossiers à synchroniser sur CE PC Idéal si peu d'espace disque.

💡 Téléphone = sync Photos seulement · PC bureau = tout · Laptop = projets actifs

Corbeille OneDrive

Fichiers supprimés = dans la Corbeille OneDrive pendant 30 jours (93 jours M365) onedrive.com → Corbeille → Restaurer Fichiers versionnés : historique disponible sur 30 jours

💡 Même si supprimé du PC = encore récupérable depuis la corbeille cloud

Slide 9

NAS — Stockage réseau dédié pour les PME

NAS = Network Attached Storage. Serveur de fichiers simplifié, toujours allumé, accessible sur le réseau.

Qu'es

Qu'est-ce qu'un NAS ?

Boîtier dédié contenant 2-8 disques durs. Interface web simple. Pas besoin de PC Windows allumé pour accéder. Principaux fabricants : Synology · QNAP · Netgear · TerraMaster

Synology DS223j = 2 baies · ~250$ · Idéal PME 5-10 utilisateurs

Usage

Usages en PME

Partage de fichiers d'équipe · Sauvegarde automatique des PCs · Streaming multimédia interne · Surveillance caméras IP · Serveur TimeMachine Mac

Remplace avantageusement un PC 'serveur de fichiers' toujours allumé

Confi

Configuration initiale

Insérer les disques · Brancher sur le réseau · Trouver l'IP (etcher.io ou Synology Assistant) · Interface web → configurer le RAID · créer utilisateurs et dossiers partagés

RAID 1 (2 disques miroir) = protection contre la panne d'un disque

Accès

Accès depuis Windows

Explorateur → \\IP_du_NAS · Ou : \\nom_nas Mapper comme lecteur réseau Z: pour accès permanent Synology Drive = synchronisation locale comme OneDrive

\\192.168.1.50\Documents → se connecte comme n'importe quel partage SMB

Slide 10

Imprimante réseau — La méthode fiable par IP directe

!

NE JAMAIS partager une imprimante via un PC hôte Windows.

Si le PC hôte s'éteint → tout le bureau perd l'accès. Toujours ajouter l'imprimante via son IP réseau directe.

1

Trouver l'IP de l'imprimante

Imprimante → Imprimer une page de configuration réseau (menu sur l'écran LCD) OU : Dans le routeur → liste des appareils DHCP → identifier l'imprimante par son nom ou MAC

2

Ouvrir l'ajout d'imprimante

Paramètres → Bluetooth et appareils → Imprimantes et scanners → Ajouter un appareil → Attendre quelques secondes → cliquer 'L'imprimante voulue n'est pas répertoriée'

3

Choisir la méthode TCP/IP

Sélectionner 'Ajouter une imprimante avec une adresse TCP/IP ou un nom d'hôte' → Type d'appareil : Détection automatique · Adresse : saisir l'IP de l'imprimante

4

Installer le driver

Windows détecte automatiquement le modèle dans la plupart des cas Si non détecté : aller sur le site du fabricant · télécharger le driver exact du modèle

5

Imprimer une page de test

Clic droit sur l'imprimante ajoutée → Propriétés de l'imprimante → Imprimer une page de test Vérifier la mise en file d'attente et la qualité

6

Attribuer une IP fixe

Dans le routeur → réservation DHCP par adresse MAC de l'imprimante Assure que l'imprimante garde toujours la même IP → connexion stable

Slide 11

Règle 3-2-1 — Le standard de sauvegarde industrie

S'applique aux particuliers comme aux PME. Mémorisez cette règle — elle sauvera des données un jour.

3

3 copies de vos données

L'original sur votre PC + 2 sauvegardes séparées. Si 1 copie est corrompue ou chiffrée (ransomware), 2 autres restent intact et disponibles.

Exemple concret : Fichier Word original + copie disque ext. + copie OneDrive

2

2 supports différents

Ne pas avoir 2 copies au même endroit sur le même type de média. Deux disques USB identiques de la même marque achetés ensemble peuvent tomber en même temps.

Exemple concret : SSD interne + disque externe USB · Pas 2 clés USB identiques

1

1 copie hors site

Cloud (OneDrive, Backblaze) OU disque chez un proche OU coffre. Protège contre incendie, vol, inondation, ransomware réseau. Si tout est au même endroit = 0 vraie protection.

Exemple concret : OneDrive 1 TB M365 · ou disque ext. stocké à l'extérieur du bureau

Une sauvegarde non testée n'est pas une sauvegarde. Tester = restaurer 1 fichier et vérifier son intégrité.

Dépannage — Partage réseau inaccessible

Deux erreurs distinctes : 'Accès refusé' (permissions) vs 'Introuvable' (réseau). Méthode différente pour chacune.

Erreur : L'ordinateur distant est introuvable

Ping NomPC → répond ? · Ping IP → répond ? · Découverte réseau activée ? · Pare-feu Windows bloque SMB ?

net view \\NomPC · ou explorer.exe \\IP

Erreur : Accès refusé (0x80070005)

Vérifier permissions de partage (Propriétés → Partage → Partager) Vérifier permissions NTFS (onglet Sécurité) La plus restrictive des 2 s'applique

Ajouter l'utilisateur dans les 2 onglets :

Erreur : Ressource réseau absente

Partage supprimé · PC hôte éteint · Chemin UNC incorrect Vérifier que le PC hôte est allumé · Que le partage existe encore

net share → lister les partages actifs sur

Lecteur réseau déconnecté (X rouge)

PC hôte était éteint au démarrage · Le montage automatique a échoué Réinitialiser : Ouvrir l'explorateur → clic droit → Déconnecter → Remonter

net use Z: /delete puis net use Z: \\NomPC

Lenteur du partage réseau

Câble Gigabit ? · Switch Gigabit ? · Wi-Fi au lieu de câble ? Les transferts sur Wi-Fi peuvent être 5-10× plus lents qu'en câble

Task Manager → Réseau · Ou : Paramètres Et

Montrer les 5 icônes : nuage bleu (online) · cercle vert plein (sync local) · cercle vert vide (dispo hors ligne) · flèches (sync en cours) · X rouge (erreur)

Les 5 icônes OneDrive dans l'Explorateur :

☁ Bleu

En ligne seulement — pas sur ce PC · téléchargé à l'ouverture

✓ Vert plein

Synchronisé localement — copie sur ce PC disponible hors ligne

✓ Vert vide

Disponible hors ligne — marqué explicitement pour conservation locale

↻ Bleu

Synchronisation en cours — ne pas éteindre

✗ Rouge

Erreur de synchronisation — voir les détails en cliquant sur l'icône barre des tâches
