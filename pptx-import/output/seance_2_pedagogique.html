≈ 1 heure

Slide 6

🖥️ RÔLE TECHNIQUE RÉEL DE LA CARTE MÈRE

Imaginez la carte mère comme le coffret électrique principal d'un chantier : elle distribue le courant, relie tous les composants et coordonne le démarrage. Sans elle, rien ne fonctionne.

1

Distribution électrique

Achemine les tensions ATX (+12V, +5V, +3.3V) vers chaque composant via les VRM. Comme un tableau électrique qui distribue le courant sur un chantier.

2

Bus de communication

Fait transiter les données entre CPU, RAM, GPU et stockage. Comme les tuyaux hydrauliques d'un engin de chantier.

3

Initialisation matérielle

Lance le POST (auto-test) via le BIOS/UEFI au démarrage. Vérifie que tout est présent avant de passer la main à Windows.

4

Contrôleurs intégrés

Gère directement les ports USB, SATA, PCIe, audio et réseau. Tout ce qu'on branche passe obligatoirement par elle.

Si la carte mère est défaillante → le PC peut ne pas s'allumer, s'allumer partiellement ou démarrer aléatoirement. On la suspecte EN DERNIER (après PSU, RAM et CPU).

🔍 ANATOMIE D'UNE CARTE MÈRE — Zoom Slots RAM (2/2)

Règles d'installation RAM :

Dual Channel :

Insérer 2 barrettes identiques dans les slots de MÊME couleur. Ex : A1 + B1, ou A2 + B2. Gain de performance : +15 à 30 % sur les calculs mémoire. Les couleurs sur la carte mère vous guident.

⚠️ Règle de départ :

Si vous avez UNE seule barrette pour tester → toujours commencer par le slot A2 (ou DIMM2). C'est le slot prioritaire indiqué dans le manuel.

À reconnaître :

Verrou blanc/noir en bas de chaque slot. Détrompeur → empêche la mauvaise insertion. Broches dorées visibles = contacts électriques.

⚙️ LE PROCESSEUR (CPU) — LE CERVEAU DE LA MACHINE

NotionExplication simple
Cœurs (cores)Nombre d'ouvriers en parallèle. 6 cœurs = 6 tâches simultanées.
ThreadsChaque ouvrier peut faire 2 choses à la fois → optimisation.
Fréquence (GHz)Vitesse réelle. 3,5 GHz = 3,5 milliards d'opérations/seconde.
ThrottlingAuto-ralentissement si trop chaud — protection avant la coupure.

Le CPU c'est comme le conducteur d'un camion : il reçoit les instructions, prend les décisions et coordonne tout. Sans lui, la machine est une carcasse vide. Mal refroidi, il ralentit ou s'éteint d'urgence sans prévenir.

🌡️ PROTECTION THERMIQUE DU CPU — CE QUI SE PASSE VRAIMENT

Schéma pédagogique SAMO Formation — températures indicatives

Checklist de vérification CPU :

🔍 Les 4 vérifications obligatoires :

1. Le ventilateur CPU tourne-t-il normalement ? (Vérifier visuellement en démarrant le PC) 2. La pâte thermique est-elle présente et non craquelée ? (Gris argenté entre CPU et dissipateur) 3. Le dissipateur est-il bien fixé ? (4 clips plastiques ou 4 vis — aucun jeu) 4. Lire la température en direct avec HWMonitor (gratuit). → Normal : < 75°C en charge | < 45°C au repos.

⛔ Thermal Shutdown :

Coupure nette à 100°C — le CPU se protège. L'usager dit : « Mon PC s'éteint tout seul sans raison ». → Vérifier TOUJOURS le refroidissement en premier.

⚠️ Thermal Throttling :

Ralentissement automatique pour refroidir. L'usager dit : « Mon PC est devenu très lent ». → Même cause : refroidissement insuffisant.

Sur Teams, le formateur vous montre des barrettes réelles. Voici le comparatif pour identifier la génération en un coup d'œil.

⚠️ Incompatibilité physique absolue :

DDR3 / DDR4 / DDR5 sont INCOMPATIBLES entre elles — le détrompeur (encoche) empêche physiquement la mauvaise insertion. Si ça force lors de l'insertion → c'est le mauvais type. Ne JAMAIS forcer un composant électronique.

💡 Comment identifier sans regarder l'étiquette :

Comptez les broches dorées en bas : 240 = DDR3 | 288 = DDR4 ou DDR5 Regardez la position de l'encoche (détrompeur) : à gauche = DDR3 | centre-gauche = DDR4 | centre = DDR5 La tension d'alimentation est aussi marquée sur l'étiquette collée sur la barrette : 1.50V = DDR3 / 1.20V = DDR4 / 1.10V = DDR5

Slide 21

🚨 DIAGNOSTIC & PANNES DE RAM — MÉTHODE PAS À PAS

Une défaillance RAM bloque immédiatement le cycle de démarrage à l'étape 4 (POST mémoire). Le PC ne peut pas continuer vers Windows.

Signaux physiques d'alerte :

🔊 Bips répétés longs et stridents La carte mère envoie un code sonore d'erreur RAM. → Série de 3 bips longs = RAM non détectée. 🔴 Q-LED DRAM allumée fixe (orange ou rouge) Visible sur la carte mère à côté des slots RAM. → Indique exactement l'étape bloquée. 📺 Écran totalement noir au démarrage Le POST n'atteint pas l'étape affichage vidéo. → Ni logo, ni texte, ni bip unique de validation.

Méthode d'isolation — étape par étape :

1

Éteindre PC + procédure décharge résiduelle

2

Retirer TOUTES les barrettes RAM du PC

3

Souffler les slots à la bombe d'air sec

4

Insérer UNE SEULE barrette dans le slot A2

5

Démarrer → si OK, tester les autres une à une

6

Si toujours KO → tester dans un autre slot

🧰 Test approfondi : MemTest86 (gratuit — www.memtest86.com)

→ Créer une clé USB bootable avec Rufus (rufus.ie) — démarrer dessus, totalement SANS Windows. → Lancer au moins 2 passes complètes (1 à 3 h selon quantité RAM). → Un seul bloc rouge = barrette défectueuse → remplacement immédiat.

Slide 23

✅ ORDRE STRICT DE TEST — LA MÉTHODE QUI NE TROMPE PAS

RÈGLE ABSOLUE : Ne jamais changer plusieurs éléments à la fois. Si vous changez RAM + câble + BIOS en même temps → vous ne saurez jamais lequel a résolu le problème. → UNE seule variable à la fois. Toujours noter chaque action dans le ticket support.

1

⚡ PSU — Alimentation

Vérifier les tensions ATX avec un multimètre. Câbles ATX 24 broches et EPS 8 broches bien branchés. Voyant arrière allumé ?

Pas de voyant → PSU mort ou prise HS

2

💾 RAM — Une seule barrette

Retirer toutes les barrettes → 1 seule dans slot A2. Souffler les slots à l'air sec. Tester une par une si plusieurs barrettes.

Cause n°1 — toujours commencer ICI

3

🔧 Reset BIOS / pile CMOS

Retirer pile CR2032 → attendre 30 s → remettre. Reconfigurer l'heure et l'ordre de boot. Résout 30 % des pannes de démarrage.

Résout les bugs de config BIOS

4

⚙️ CPU — Refroidissement

Vérifier pâte thermique, rotation ventilateur, fixation dissipateur (4 clips). Lire températures avec HWMonitor (logiciel gratuit).

Shutdown = CPU surchauffé

5

🖥️ Carte mère — EN DERNIER

Suspecter UNIQUEMENT après avoir prouvé que les 4 étapes précédentes sont saines. Remplacement coûteux et irréversible.

Coûteux — ne pas précipiter

✅ CORRIGÉS — RAISONNEMENT DU TECHNICIEN

Le raisonnement compte autant que la réponse — expliquez POURQUOI à votre formateur sur Teams.

1

Écran noir + ventilateurs à fond

→

RAM / GPU / BIOS

1. Vérifier Q-LED. 2. Retirer RAM → 1 barrette slot A2. 3. Si KO → câble vidéo. 4. Reset BIOS.

🧠 Pourquoi ? — Ventilateurs = PSU OK (étape 1 passée). Pas d'image = bloqué étapes 2–4.

2

Redémarrages aléatoires en charge

→

RAM / CPU / PSU

1. Tester RAM une barrette. 2. Vérifier temp CPU avec HWMonitor. 3. Mesurer tensions PSU.

🧠 Pourquoi ? — Redémarrage = coupure de protection → thermique ou instabilité mémoire.

3

3 bips longs après nettoyage

→

RAM mal réinsérée

1. Éteindre + décharge. 2. Retirer barrettes → souffler slots. 3. Réinsérer 1 seule en A2 — appuyer FORT jusqu'au clic.

🧠 Pourquoi ? — Nettoyage = barrette déplacée. 3 bips longs = code POST « mémoire non détectée ».

Synthèse : Bips → RAM | Écran noir → tester depuis étape 2 | Redémarrages → RAM puis CPU puis PSU. Toujours dans cet ordre.
