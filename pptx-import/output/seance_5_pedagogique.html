Slide 3

💻 LES PRÉREQUIS OFFICIELS WINDOWS 11

Spécifications Minimales

Processeur : 1 GHz ou plus, 2 cœurs ou plus, compatible 64 bits (Intel Gen 8+ / AMD Zen 2+). Mémoire Vive (RAM) : 4 Go minimum (8 Go fortement recommandés). Stockage : 64 Go ou plus (SSD obligatoire pour une bonne expérience). Firmware : UEFI, compatible Secure Boot.

Le Point Critique : La Sécurité

TPM (Trusted Platform Module) : Version 2.0 obligatoire. Puce physique ou firmware fTPM/Intel PTT. Carte Graphique : Compatible DirectX 12 avec pilote WDDM 2.0. Écran : Haute définition (720p) supérieure à 9" diagonale.

Diagnostic Pro : Le processeur et le TPM 2.0 constituent 90% des causes d'incompatibilité signalées par l'assistant Microsoft.

Slide 4

🔒 DÉCODER TPM 2.0 ET SECURE BOOT

TPM 2.0 : Qu'est-ce que c’est ?

Composant cryptographique sécurisé. Il génère et stocke les clés de chiffrement (ex: BitLocker, Windows Hello) à l'abri des attaques logicielles directes.

Secure Boot : Rôle

Protocole UEFI qui empêche l'exécution de chargeurs de démarrage ou de pilotes non signés (rootkits) lors de la mise sous tension du PC.

Pourquoi l'imposer

Établir une barrière de sécurité matérielle (Zero Trust). Réduit drastiquement l'efficacité des malwares au démarrage du système.

Conseil Tech : Si absent, vérifiez si l'option Intel PTT ou AMD fTPM est activée dans le BIOS/UEFI.

Slide 5

🛠️ RUFUS VS VENTOY : QUEL OUTIL CHOISIR ?

Rufus : Le Standard Robuste

Le concept : Formate une clé USB spécifique pour un seul fichier ISO. Option Windows To Go : Permet de créer un système Windows exécutable directement depuis la clé USB. Contournement intégré : Possibilité de cocher des cases pour supprimer l'exigence de TPM, de Secure Boot et de compte Microsoft en un clic.

Ventoy : Le Multi-Boot Moderne

Le concept : Installe Ventoy sur la clé une seule fois, puis glissez-déposez simplement les fichiers ISO. Avantage majeur : Stocke plusieurs OS sur la même clé (Windows 10, 11, Linux, utilitaires de dépannage). Contournement : Nécessite l'injection d'un fichier de configuration XML (Ventoy.json) pour contourner le TPM.

Slide 7

⚙️ UEFI VS LEGACY BIOS : POURQUOI C'EST VITAL

Legacy BIOS (Hérité)

Ancien système de démarrage (années 80). Ne gère que les disques partitionnés en MBR (limité à 2 To). Non compatible avec les sécurités Windows 11.

UEFI (Moderne)

Interface moderne, rapide et graphique. Obligatoire pour Windows 11. Gère le partitionnement GPT, le démarrage sécurisé et les clés cryptographiques.

Le Piège au Démarrage

Si la clé d'installation est démarrée en mode Legacy alors que le disque est configuré en UEFI (ou vice-versa), l'installation refuse de continuer.

Slide 8

💾 PARTITIONNEMENT : MBR VS GPT

128

PARTITIONS MAX EN GPT

Les limitations physiques du disque

MBR (Master Boot Record) : Limité à 4 partitions principales et un maximum de 2 To par disque. Obsolète. GPT (GUID Partition Table) : Supporte des disques de plus de 9 Zettaoctets (9 milliards de To) et permet jusqu'à 128 partitions sans recourir aux partitions étendues.

Rappel de cours : Windows 11 exige obligatoirement GPT pour son disque système afin de pouvoir amorcer en mode UEFI.

Slide 9

🚀 PROCESSUS D'INSTALLATION STANDARD

1. Boot USB

Accéder au Boot Menu (F12, F11, Esc) et démarrer sur le média d'installation.

2. Clé Produit

Saisir la clé de licence ou cliquer sur 'Je n'ai pas de clé produit'.

3. Personnalisé

Choisir l'option 'Personnalisé : installer uniquement Windows (avancé)'.

4. Partitions

Supprimer les anciennes partitions pour obtenir un 'Espace non alloué'.

5. Copie

Copie des fichiers sur le SSD suivie d'un redémarrage automatique du système.

Slide 10

🌐 LA PHASE DE CONFIGURATION OOBE

Choix de la région et du clavier : Sélectionner la disposition linguistique principale (ex: Français AZERTY) et ignorer la seconde disposition si non requise.

Connexion Réseau Obligatoire : Par défaut, Windows 11 Home/Pro exige une connexion Internet active pour poursuivre la configuration.

Création de Compte : Microsoft impose l'usage d'un compte en ligne (Outlook, Hotmail) pour finaliser l'initialisation du poste.

Paramètres de Confidentialité : Désactivez les options de localisation, données de diagnostic complets, identifiant publicitaire pour optimiser les performances.

Slide 11

💡 ASTUCE : CRÉER UN COMPTE LOCAL

Bypass

OOBE \ BYPASSNRO

Contourner l'obligation de compte en ligne

Lors de l'étape de connexion réseau obligatoire, si vous préférez installer le système avec un compte local hors-ligne : 1. Appuyez simultanément sur Shift + F10 pour ouvrir l'invite de commandes. 2. Saisissez la commande : OOBE\BYPASSNRO et validez par Entrée. 3. Le système redémarre. Cliquez sur 'Je n'ai pas d'Internet' pour créer votre compte local d'administrateur.

Slide 12

🗄️ GESTION DES PARTITIONS POST-INSTALL

Initialisation de disques secondaires : Clic droit sur démarrer > Gestion des disques. Initialiser les nouveaux disques physiques détectés en mode GPT.

Réduction de volume (Shrink) : Libérer de l'espace sur la partition C: pour créer une partition distincte dédiée aux données de l'utilisateur.

Extension de volume : Possible uniquement si de l'espace non alloué est situé *immédiatement à droite* de la partition à étendre.

Le Piège des disques Dynamiques : Ne convertissez pas un disque de base en disque dynamique sous peine de compliquer la récupération de données.

🔌 GESTION DES PILOTES ET PÉRIPHÉRIQUES

Identifier l'inconnu

Dans le Gestionnaire de périphériques, repérez les icônes jaunes. Clic droit > Propriétés > Détails > Hardware ID pour identifier le composant exact sur le web.

Mise à jour Windows

Constructeur (OEM)

Privilégiez les utilitaires d'origine constructeur (Dell Command Update, Lenovo Vantage, HP Support Assistant) pour les composants critiques.

Slide 14

🔄 STRATÉGIES WINDOWS UPDATE

Heures d'activité : Configurez l'intervalle horaire d'usage pour interdire au PC de redémarrer automatiquement pendant que l'utilisateur travaille.

Interruption temporaire : Possibilité de suspendre les mises à jour jusqu'à 5 semaines en cas de déploiement critique en entreprise ou réseau limité.

Optimisation de livraison : Permet au PC de récupérer les packages de mises à jour directement auprès d'autres PC du réseau local (Peer-to-Peer).

Mises à jour de qualité vs de fonctionnalités : Les correctifs de sécurité (Qualité) sont mensuels. Les montées de version (Fonctionnalités) sont annuelles.

Slide 15

OPTIMISATION ET BLOATWARE

Éliminer le Superflu (Bloatware)

Le problème : Windows 11 pré-installe des applications promotionnelles qui encombrent inutilement l'espace disque. Méthode manuelle : Désinstaller via Paramètres > Applications installées. Scripting (Avancé) : Utilisation d'outils éprouvés (ex: SophiApp, Win11Debloat) pour purger proprement la télémétrie et les packages inutiles.

Alléger le Démarrage

Gestionnaire des tâches : Onglet 'Applications de démarrage'. Désactivez les processus secondaires (ex: Teams, Spotify, OneDrive, etc.). Effet : Réduit radicalement le temps d'allumage du PC et l'allocation de la RAM par défaut au repos. Rappel de sécurité : Ne désactivez jamais l'antivirus ni les services et pilotes système vitaux.

Slide 16

🛡️ SÉCURITÉ : BITLOCKER & DEFENDER

Chiffrement BitLocker

Protège le contenu du disque en cas de vol du PC. Nécessite une puce TPM fonctionnelle. Sauvegardez la clé de récupération (48 chiffres) hors du PC (Cloud ou USB).

Windows Defender

Antivirus natif puissant, léger et transparent. Se désactive automatiquement si un antivirus tiers certifié est installé.

Isolation du Noyau

Vérifiez que l'intégrité de la mémoire est activée (Paramètres > Sécurité des appareils). Empêche l'injection de code malveillant dans les processus système critiques.

Slide 17

📦 SAUVEGARDE ET RESTAURATION

Point de restauration : Sauvegarde l'état du registre et des fichiers système critiques avant l'installation d'un pilote ou d'une mise à jour logicielle.

Création manuelle : Saisir sysdm.cpl > Protection du système > Activer la protection pour le lecteur C: et cliquer sur Créer.

Image Système : Outil historique de sauvegarde dans le Panneau de configuration. Permet de cloner l'intégralité du disque système sur support externe.

Restauration d'usine (Reset) : Réinstallation de Windows intégrée à l'OS. Offre le choix entre conserver les fichiers personnels ou tout effacer.
