Slide 5

FIL CONDUCTEUR

Méthode universelle — S'applique à toutes les pannes

Identifier

Symptôme exact, depuis quand, changement récent, un ou tous les appareils ?

Hypothèse

UNE cause probable. Physique avant logiciel. Une variable à la fois.

Tester

Vérifier l'hypothèse avec une seule modification. Si faux, nouvelle hypothèse.

Résoudre

Appliquer la solution. Confirmer avec le client que tout fonctionne.

5

Documenter

Ticket complet : symptôme + cause + solution + durée, même pour un appel de 3 minutes.

Le redémarrage résout 50 % des problèmes — toujours l'essayer avant d'aller plus loin

Slide 6

Panne 1 — PC ne démarre pas

« Le PC n'affiche rien, aucun voyant, ou démarre puis s'éteint immédiatement. »

Alimentation

Vérifier câble, prise, interrupteur du bloc d'alimentation.

RAM

Réinsérer les barrettes dans le slot A2, tester une seule barrette à la fois.

Disque (BIOS)

Vérifier que le BIOS détecte le disque de démarrage.

Carte mère

Si rien ne fonctionne, suspecter la carte mère — escalade N2.

Toujours commencer par le physique : câbles, connexions, alimentation avant tout diagnostic logiciel.

10-20 min

Slide 7

Panne 2 — BSOD récurrent

« Écran bleu qui revient plusieurs fois par jour, avec ou sans motif apparent. »

Noter le code

Toujours relever le code d'arrêt exact avant de redémarrer.

WhoCrashed

Analyser le fichier .dmp pour identifier le driver responsable.

MemTest86

Si le code pointe vers la RAM, tester avec 2 passes minimum.

SFC / DISM

Si le code pointe vers des fichiers système corrompus.

Voir la Séance 13 pour la méthode complète de diagnostic BSOD.

20-40 min

Slide 8

Panne 3 — PC très lent

« Le PC met plusieurs minutes à devenir utilisable ou rame en continu. »

Task Manager

Vérifier CPU, RAM, disque — identifier le processus coupable.

Démarrage

Désactiver les programmes inutiles au démarrage.

Espace disque

Vérifier qu'il reste au moins 10-15 % d'espace libre.

Malware

Si rien n'explique la lenteur, suspecter un malware caché.

Un seul coupable à la fois — ne pas changer plusieurs réglages en même temps.

15-30 min

Slide 9

Panne 4 — Internet coupé

« Plus de connexion Internet, sur un poste ou sur tout le réseau. »

Ping passerelle

Tester la connexion locale au routeur.

Ping 8.8.8.8

Tester la connexion Internet en dehors du DNS.

Ping google.com

Tester la résolution DNS spécifiquement.

Redémarrer la box

Si tous les pings échouent, redémarrer le modem/routeur.

Les 3 pings localisent la panne (poste, réseau local, ou Internet) en moins de 2 minutes.

5-10 min

Slide 10

Panne 5 — Virus / Malware

« Popups intempestifs, ralentissement soudain, ou comportement anormal du navigateur. »

Isoler

Déconnecter le réseau immédiatement pour éviter la propagation.

Windows Defender

Lancer une analyse complète (pas rapide).

Malwarebytes

Scan complémentaire pour les menaces que Defender manque parfois.

Vérifier navigateur

Extensions suspectes, page d'accueil modifiée.

Toujours isoler avant de nettoyer — un malware réseau peut se propager pendant l'analyse.

30-60 min

Slide 11

Panne 6 — Imprimante hors ligne

« L'imprimante réseau ou USB est signalée « hors ligne » par Windows. »

Utiliser en ligne

Clic droit → Voir ce qui s'imprime → Utiliser l'imprimante en ligne.

Vérifier le réseau

Confirmer que l'imprimante répond à un ping (IP fixe recommandée).

Redémarrer le spooler

services.msc → Print Spooler → Redémarrer si la file est bloquée.

Réinstaller le driver

Si rien ne fonctionne, réinstaller depuis le site du fabricant.

Toujours essayer « Utiliser en ligne » en premier — résout la majorité des cas en 2 minutes.

2-15 min

Slide 12

Panne 7 — Son absent

« Aucun son ne sort du PC, sur les haut-parleurs ou le casque. »

Sortie audio

Paramètres → Son → vérifier le périphérique de sortie sélectionné.

Volume et mixeur

Vérifier que l'application n'est pas mise en sourdine individuellement.

Driver audio

Gestionnaire de périphériques → vérifier l'absence de point d'exclamation.

Redémarrer le service

services.msc → Windows Audio → Redémarrer si nécessaire.

95 % des cas de « son absent » : mauvais périphérique de sortie sélectionné.

3-10 min

Slide 13

Panne 8 — Driver manquant

« Point d'exclamation jaune dans le Gestionnaire de périphériques. »

Identifier

devmgmt.msc → repérer le périphérique en erreur.

Mise à jour auto

Clic droit → Mettre à jour le pilote → Recherche automatique.

Site du fabricant

Si échec, télécharger le pilote exact depuis le site officiel.

Désinstaller/réinstaller

En dernier recours, désinstaller puis laisser Windows réinstaller.

Toujours vérifier le modèle exact du composant avant de télécharger un pilote.

5-20 min

Slide 14

Panne 9 — Mot de passe oublié

« L'utilisateur ne peut plus se connecter à sa session Windows. »

Compte Microsoft

Réinitialiser en ligne via account.live.com/password/reset.

Compte local

Utiliser WinRE ou un compte administrateur existant.

Vérifier Verr. Maj

Cause fréquente et ignorée : Verr Maj activé par erreur.

Sensibiliser

Recommander un gestionnaire de mots de passe pour éviter la récidive.

Ne jamais stocker les mots de passe clients sans un gestionnaire de mots de passe sécurisé.

10-30 min

Slide 15

Panne 10 — PC redémarre seul

« Le PC s'éteint ou redémarre de façon inattendue, surtout sous charge. »

HWMonitor

Vérifier les températures CPU/GPU — cause n°1 de ce symptôme.

Si > 90°C

Nettoyage physique + éventuellement renouveler la pâte thermique.

Si température normale

Vérifier l'Observateur d'événements pour un code BSOD masqué.

Alimentation

Suspecter le bloc d'alimentation si rien d'autre n'explique le symptôme.

Si un BSOD précède le redémarrage, voir la Séance 13 pour le diagnostic complet.

15-45 min

Slide 17

PRIORISATION

Plusieurs symptômes en même temps — Que traiter en premier ?

Priorité 1 — Sécurité

Virus / Malware suspecté Toujours isoler avant tout autre diagnostic Un malware actif peut aggraver d'autres symptômes

Priorité 2 — Disponibilité

PC ne démarre pas ou redémarre seul Bloque totalement le travail du client Diagnostic physique rapide en premier

Priorité 3 — Confort

Son absent, imprimante hors ligne, lenteur N'empêchent pas le travail, mais gênent Peuvent être traités après stabilisation

Un client avec 3 symptômes en même temps a souvent une cause commune — chercher le lien avant d'isoler chaque cas

Piste : HWMonitor d'abord → si normal, analyser le BSOD (Séance 13)

Cas 3 — Tarek, ex-mécanicien

Quelle panne traiter en priorité ? Comment sécuriser l'accès sans compromettre le diagnostic ? Quelle méthode suivre pour chaque panne ?

Piste : Sécuriser l'accès d'abord (priorité 1), puis traiter le mot de passe
