Slide 8

Le modèle de licence par cœurs

Depuis 2016, Windows Server ne se licencie plus par processeur

Chaque licence de base couvre 16 cœurs (répartis sur 2 processeurs). Au-delà, des packs de cœurs supplémentaires doivent être ajoutés par tranche de 2.

EXEMPLE DE CALCUL

Serveur : 2 x CPU de 12 cœurs = 24 cœurs Licence de base couvre : 16 cœurs Cœurs supplémentaires requis : 8 → 4 packs de 2 cœurs

!

CAL (Client Access License)

Chaque utilisateur ou périphérique qui accède au serveur nécessite en plus une CAL (User CAL ou Device CAL) — indépendante de la licence serveur elle-même.

MINIMUMS À RETENIR

Slide 11

Windows Admin Center (WAC)

La console moderne qui remplace peu à peu la gestion locale

Windows Admin Center est une console web légère, installable gratuitement, qui centralise l'administration de serveurs physiques, virtuels et de clusters — sans dépendre de MMC. Approfondi en Séance 12, elle sera notre principal point d'entrée pour la gestion à distance des serveurs Core à partir de la deuxième moitié du cours.

◆

Ce qui change selon la version

2019 : WAC s'installe séparément (outil distinct). 2022 : intégration plus poussée, extensions Azure natives. 2025 : interface repensée façon Windows 11, ajout de nouveaux tableaux de bord de santé.

Slide 12

System Insights : la supervision prédictive

Anticiper les pannes plutôt que les subir

System Insights est une fonctionnalité locale qui utilise des modèles d'apprentissage automatique embarqués pour prévoir, à partir des journaux du serveur, des problèmes avant qu'ils ne surviennent (saturation disque, dérive d'horloge, surcharge réseau...).

📉 Capacité de stockage

Prévoit la date probable de saturation d'un volume

🌐 Utilisation réseau

Détecte les tendances anormales de trafic

⏱ Dérive d'horloge

Alerte avant une désynchronisation critique

🔥 Utilisation CPU/mémoire

Anticipe la saturation des ressources

Slide 13

Nouveautés majeures de Windows Server 2025

Ce qui distingue vraiment la dernière génération

🩹 Hotpatching

Applique les correctifs de sécurité sans redémarrage du serveur — disponible aussi en Standard, plus seulement Azure Edition.

🛡 Credential Guard par défaut

Isole les identifiants en mémoire virtualisée dès l'installation, sans configuration manuelle.

📡 SMB over QUIC en Standard

Le partage de fichiers chiffré sur QUIC, auparavant réservé à l'Azure Edition, arrive en édition Standard.

🗄 AD DS : bases élargies

Support d'une base de données AD élargie (pages de 32k) pour les très grands annuaires.

Slide 14

Le socle on-premises ne travaille plus seul

Depuis 2019, Microsoft investit fortement dans les scénarios hybrides : un serveur on-premises peut être rattaché, sauvegardé, mis à jour et surveillé depuis Azure — sans migration complète vers le cloud.

1

Azure AD Connect

synchronise les identités locales vers le cloud

2

Azure Arc

projette les serveurs on-premises dans le portail Azure

3

Azure Backup / Update Mgmt

centralise sauvegardes et correctifs
