Les 4 phases du démarrage Windows

1

POST / BIOS-UEFI

Auto-test matériel, avant tout logiciel OS

→

2

Bootloader (BCD)

Localise et charge le système d'exploitation

→

3

Kernel Windows

Charge le noyau et les pilotes essentiels

→

4

Session utilisateur

Charge le profil, le bureau, Explorer.exe

Pourquoi connaître ces 4 phases ?

Chaque message d'erreur ou symptôme appartient à UNE seule phase — cela élimine 75 % des hypothèses fausses avant même de commencer à tester quoi que ce soit. Un blocage en phase 1-2 (avant le logo) = jamais un problème de profil ou de pilote logiciel.

BLOC 2 — BONNES PRATIQUES

Erreurs classiques à éviter face à un message

❌

Réinstaller au premier message

Un message n'est pas toujours ce qu'il semble être — 50 % se résolvent avec WinRE seul.

❌

Ignorer le message exact

Les stop codes et messages orientent précisément la cause — les paraphraser fait perdre l'information clé.

❌

Confondre erreur disque et erreur Windows

'Inaccessible boot device' peut venir d'un réglage BIOS, pas forcément d'un disque mort.

✅

Noter le message mot pour mot

Photo ou capture d'écran avant toute action — la formulation exacte guide tout le diagnostic.

BLOC 3 — ≈ 50 MINUTES

Écrans bleus (BSOD) : comprendre sans paniquer

Ce qu'est un BSOD

Windows a détecté une erreur critique et s'arrête volontairement pour PROTÉGER le système avant qu'un dommage plus grave ne survienne.

✅ Un BSOD n'est pas « la mort du PC ». C'est un mécanisme de sécurité.

Stop code

Type d'erreur — ex : MEMORY_MANAGEMENT

Fichier .sys

Pilote concerné — ex : nvlddmkm.sys

Moment d'apparition

Démarrage / usage intensif / aléatoire

🎯 On cherche la CAUSE, pas le code seul — le stop code oriente, ne conclut pas.

WinRE — Accéder aux outils de récupération

1

3 redémarrages forcés consécutifs

Coupez l'alimentation 3 fois pendant le chargement Windows — méthode d'urgence quand rien d'autre ne répond.

2

Shift + Redémarrer

Depuis Windows démarré normalement : Menu Démarrer → maintenir Shift → cliquer Redémarrer.

3

Clé USB Windows bootable

Créée avec Rufus ou Media Creation Tool — nécessaire si le disque système est totalement inaccessible.

Slide 14

BLOC 4 — BOÎTE À OUTILS

Les 5 outils de récupération WinRE

1

Startup Repair

Corrige automatiquement les problèmes de démarrage

2

System Restore

Revenir à un état système antérieur stable

3

Safe Mode

Démarrer sans pilotes tiers pour isoler la cause

4

Command Prompt

Réparer manuellement (bcdedit, sfc, chkdsk)

5

Reset this PC

Réinstallation propre, avec ou sans conservation des fichiers

🛡️ Safe Mode — votre meilleur allié

Démarre Windows avec uniquement les pilotes Microsoft essentiels → désinstaller le pilote fautif → tester la stabilité → vérifier si la cause est matérielle ou logicielle. ✅ Si le PC est stable en Safe Mode, le matériel est OK : le problème est logiciel ou pilote.

Slide 16

BLOC 5 — DÉCISION

Réinstaller Windows — quand et comment

La réinstallation est une solution de dernier recours, pas un outil de diagnostic.

✅ Quand réinstaller ?

Corruption grave et irréparable du système Système instable après toutes les tentatives de réparation Malware sérieux impossible à éradiquer Demande explicite de l'utilisateur après sauvegarde

❌ Quand NE PAS réinstaller ?

Panne matérielle non résolue Problème BIOS ou stockage non diagnostiqué Disque défectueux non confirmé Simple message d'erreur sans test préalable

Slide 17

BLOC 5 — PROCÉDURE

Procédure minimale avant toute réinstallation

1

Sauvegarder TOUTES les données

Documents, Bureau, images, licences — vérifier l'intégrité de la sauvegarde avant de continuer.

2

Lister logiciels et clés de licence

Noter tous les logiciels installés et leurs clés pour pouvoir tout réinstaller ensuite.

3

Confirmer la réactivation de la licence

Windows 10/11 est généralement lié au compte Microsoft — vérifier avant de formater.

4

Vérifier que le matériel est sain

AVANT de réinstaller : RAM, disque, alimentation testés et confirmés fonctionnels.

MISE EN PRATIQUE — SUITE

Corrigés — synthèse des 3 exercices

BSOD MEMORY_MANAGEMENT

→ Tester la RAM avec MemTest86 (2 passes min.) ou barrette par barrette dans le slot A2.

Boucle « automatic repair »

→ WinRE + sfc /scannow + chkdsk. Si toujours en échec : envisager Reset this PC après sauvegarde.

Écran noir après login

→ Safe Mode, désactiver le pilote vidéo suspect, ou réparer le profil utilisateur (NTUSER.DAT).
